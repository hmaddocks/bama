# Domain docs

Single-context.

## Before exploring, read these

- `.claude/CLAUDE.md` (the same text as `AGENTS.md`): the repo layout and
  the rules for writing skills.
- The Bear spec for the stage you are working on, named in the OmniFocus
  action's note.
- The umbrella spec, Bear note "BAMA spec: AppKit, UIKit and OmniFocus
  planning", for the direction of the fork.

## Flag decision conflicts

If your work contradicts a decision in a spec or in an action's
"Decisions so far:", say so and name where the decision is, rather than
overriding it.
