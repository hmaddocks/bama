# Triage labels

Triage state is an OmniFocus tag nested under the group "BAMA triage".

| Label | Meaning |
| --- | --- |
| `needs-triage` | Henry needs to look at it |
| `needs-info` | Waiting for more information |
| `ready-for-agent` | Fully specified. An agent can finish it alone |
| `ready-for-human` | Needs Henry's judgement or a check by hand |
| `wontfix` | Will not be done |

An agent works only on tickets tagged `ready-for-agent`.
