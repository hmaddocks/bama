# Domain docs

Single-context.

## Before exploring, read these

- `CONTEXT.md`: the glossary and the decisions. Add new terms there.
- The Bear spec for the milestone you are working on, named in the
  OmniFocus action's note.

## Use the glossary's vocabulary

Name concepts in ticket titles, test names and code with the glossary's
term. If a concept is not there, either you are inventing language
(reconsider) or there is a gap (add the term to `CONTEXT.md`).

## Flag decision conflicts

If your work contradicts a decision in `CONTEXT.md`, say so and name the
decision, rather than overriding it silently.
