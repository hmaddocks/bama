# Triage labels

Triage state is an OmniFocus tag nested under the group
"__APP_NAME__ triage".

| Label | Meaning |
| --- | --- |
| `needs-triage` | Needs a look before anyone works on it |
| `needs-info` | Waiting for more information |
| `ready-for-agent` | Fully specified. An agent can finish it alone |
| `ready-for-human` | Needs a person's judgement or a check by hand |
| `wontfix` | Will not be done |

An agent works only on tickets tagged `ready-for-agent`.
